# Prohibited uses

gp3mlpy is intended only for explicitly observed, non-sensitive outcomes used for declared scientific purposes.

It must not be used to enable or infer:

- person identification or biometric authentication;
- health status, diagnosis, disease, or protected attributes;
- emotion or stress;
- personality;
- deception;
- cognition or comprehension;
- intent;
- other latent mental-state inference.

Custom/black-box engines require explicit acknowledgements that prohibited uses are understood, prediction-time inputs are used appropriately, and group-aware evaluation remains required.
