# Governance Evidence and Standards Crosswalks

> Source-derived companion to `gp3ml` 0.3.0 vignette `governance-standards-profile.Rmd`. R code blocks are omitted here; the Python companion script is under `examples/governance-standards-profile.py`.

gp3ml can organize package evidence into a native governance profile or an
orientation crosswalk for NIST AI RMF 1.0, ISO/IEC 23894, or ISO/IEC 42001.

These are documentation crosswalks only. They are **not** evidence of NIST
endorsement, ISO conformity, certification, or legal compliance.



The profile is intentionally evidence-oriented: missing evidence is surfaced for
review rather than converted into a synthetic compliance score.
